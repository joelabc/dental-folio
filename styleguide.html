Internal reference

Site components and usage guide.

Copy any markup snippet below into a page that links assets/css/styles.css and includes the inline document.documentElement.classList.add('js') bootstrap. All components inherit the shared brand identity automatically.

Foundations Typography Buttons Chips & Eyebrows Layout shells Page intro Cards Story panel Testimonials CTA banners Forms Imagery Sales funnel Promotions Pricing Badges Countdown Lead capture Footer
Stack

Pure HTML, CSS, JS

No build step. Every component is a copy-paste block that respects the design tokens defined in :root.

Tokens

Tokens drive everything

Colors, radii, gutters, and shadows come from CSS variables, so theming is centralized.

01 · Foundations

Design tokens.

All colors and spacing read from CSS custom properties on :root. Override them in a single place to retheme the site.

Color palette
Background--bg
Elevated--bg-elevated
Text / Accent--text / --accent-dark
Muted--text-muted
Gold--gold
Gold soft--gold-soft
:root {
  --bg: #fbfaf7;
  --text: #171717;
  --text-muted: #6b655c;
  --gold: #c9a227;
  --accent-dark: #111111;
  --container: 1180px;
  --gutter: clamp(1rem, 2.5vw, 1.5rem);
  --radius-lg: 24px;
  --radius-md: 16px;
}
02 · Typography

Headlines and body.

All headings auto-scale with clamp() and use text-wrap: balance for editorial line breaks.

H1 — The premium headline.

<h1> · clamp(2.4rem, 5.4vw, 5.2rem)

H2 — Section headline.

<h2> · clamp(1.9rem, 4vw, 3.2rem)

H3 — Sub-section headline.

<h3> · clamp(1.5rem, 2.2vw, 2rem)

Section lead. A longer, slightly muted paragraph used to support a section headline.

<p class="section-lead">

Body paragraph. Default site text uses Plus Jakarta Sans at roughly 17px with comfortable line-height for readability.
